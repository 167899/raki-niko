# Тема сайту Raki Niko

Сайт rakiniko.com.ua — звичайна тема WordPress. Сторінки збирає PHP на сервері (добре для Google і реклами), а кошик, оформлення й «Мої замовлення» працюють у браузері через той самий API `raky/v1`, що й застосунок.

## Звідки дані

Тема нічого не зберігає сама. Товари, ціни, калібри, смаки, «Додатково», акції, новини, точки й зони беруться функціями плагіна `raky-shop` (`raky_rest_catalog()`, `raky_rest_config()`, `raky_rest_banners()`, `raky_rest_news()`). Тому сайт і застосунок завжди показують одне й те саме, а редагується все там само: WooCommerce → Товари, «Застосунок», «Банери», «Новини».

Контакти, тексти, колір акценту й коди реклами редагуються в адмінці: пункт меню **«Сайт»** (`inc/settings.php`). Там же поле Google Tag Manager (GA4, Google Ads), Meta Pixel і код підтвердження Google Search Console. Доступно адміністратору й менеджеру магазину. Застосунок ці налаштування не читає.

Замовлення з сайту надходять у WooCommerce і Telegram-бот так само, як із застосунку, і проходять ті самі статуси.

## Будова

| Де | Що |
|---|---|
| `inc/settings.php` | сторінка «Сайт» в адмінці: контакти, тексти, колір, коди аналітики |
| `inc/content.php` | телефони, години, юридичні тексти для шаблонів (з налаштувань «Сайт») |
| `inc/data.php` | каталог, картки (одна на підкатегорію-калібри), форматування цін |
| `inc/routes.php` | адреси сторінок, вибір шаблону, 404 і переадресації |
| `inc/seo.php` | заголовки, опис, canonical, Open Graph, schema.org, карта сайту |
| `inc/assets.php` | підключення зібраних `dist/` і дані для скриптів (`window.RAKY`) |
| `templates/` | розмітка сторінок, `templates/parts/` — шапка, низ, картка, банер |
| `src/` | TypeScript і CSS: кошик, промокод, оформлення, замовлення, пошук |

Адреси: товари `/tovar/…/`, категорії `/katalog/…/` (штатні адреси WooCommerce), інші сторінки — `/aktsii/`, `/novyny/`, `/dostavka/`, `/kontakty/`, `/zaproshennia/`, `/koshyk/`, `/oformlennia/`, `/zamovlennia/`, `/ulyublene/`, `/vkhid/`, `/profil/`, `/pryvatnist/`, `/oferta/`.

Улюблене, акаунт (вхід і реєстрація за телефоном) і прочитані новини, як і в застосунку, зберігаються в браузері покупця (`src/store.ts`, `src/favorites.ts`, `src/account.ts`); на сервер вони не надсилаються. Список — у `raky_site_pages()`.

Адреси нових товарів і категорій плагін `raky-latin-slugs` сам пише латиницею («Раки живі» → `raky-zhyvi`), назви завантажених файлів — теж. Якщо змінити адресу категорії, стара переадресовується на нову (для товарів це робить сам WordPress). Плагін викладається разом із темою (`deploy/deploy-site.sh`).

Зі застосунку (`mobile/src`) скрипти беруть без змін: пошук із виправленням помилок (`search.ts`), форматування (`format.ts`), вибір часу (`slots.ts`), карту зон (`map/mapHtml.ts`), іконки й типи API. Іконки для PHP генерує `npm run icons`.

## Розробка

```bash
cd backend && ./start-site.sh            # WordPress із темою на http://127.0.0.1:9410
cd backend/wp-content/themes/raky-site
npm install
npm run watch                            # перезбирає dist/ при змінах у src/
```

Відкривайте сайт саме за адресою `127.0.0.1`, а не `localhost`: інакше браузер не завантажить скрипт теми.
Перед викладкою: `npm run build` (перевірка типів і збірка).

## Реклама й аналітика

Ідентифікатори GTM і Meta Pixel вписуються в адмінці «Сайт» — код лічильників тема додає сама. Скрипт сам надсилає події `view_item`, `add_to_cart`, `begin_checkout`, `purchase` у `dataLayer` (Google Tag Manager, GA4, Google Ads) і в Meta Pixel (`fbq`), якщо їх підключено.

Карта сайту: `/wp-sitemap.xml` (товари, категорії, сторінки). Розмітка товарів (ціна, наявність) — у `inc/seo.php`.
